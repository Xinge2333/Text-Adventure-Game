你是替身：不是唯一

豪门向文游之《你是替身，不是唯一》

## 🧩 一、【主角设定】  
【主角初始设定】
身份：落魄真千金 / 替身情人 / 被换人生 / 黑月光归位者  
起始剧情背景：
- 十八岁当天，发现自己是“假千金”，被赶出池家  
- 替白月光挡过一刀，背锅四年成“戏精替身”  
- 真千金归来后，她被净身出户，含泪离开  
- 他一直爱的人，是那个说你“只是她影子”的白月光  

【基础属性】
- 情绪承受力：80（长期历练出冷感）  
- 身份危险度：95（众人皆知她是假千金）  
- 魅力值：98（商圈传闻中的“疯批美人”）  
- 反击值：解锁中（事业复仇线开启，初恋重遇线埋伏）

【初始状态】
- ✨ 拿着天才建筑师offer，重返池氏大厦  
- ✨ 孕检报告藏在复仇计划里  
- ✨ 外界盛传她是“低贱情人”，她却风光出席业界典礼  
- ✨ 他依旧冷眼旁观，嘴硬却追查她近况  
```

## 🧩 二、【世界观设定】  
【故事背景】
时空设定：现代都市 / 顶奢豪门圈 / 千亿集团权谋漩涡  
男主身份：池家继承人 / 商界神话 / 黑白通吃 / 曾失心动一次，正是你  

【豪门规则】
- 联姻是权力游戏，真感情不配谈  
- 你替她挡的那一刀，他感激，却只说“你不该出现在她面前”  
- 替身永远只是影子，影子无权拥有未来  

【关系网设定】
- 男主：冷感、绝情、曾在你怀里低语，如今一刀两断  
- 白月光：留学归来，顶着“真千金”身份复仇你  
- 男二：豪门死对头，深爱你却从不表白  
- 女反派：白月光表妹，表面闺蜜，实则你的对照组  

【狗血背景buff】
- 你是他弟弟（已故）曾深爱的白月光？  
- 他联姻的背后，竟是为换心救母？  
- 怀孕“你算计他”？可当晚监控全无，是他主动求你陪伴那一夜……  
- 真千金背后，藏着你未解开的血缘之谜（豪门遗案副本开启）

### 🎭【替身崩溃线 · 一步错，步步错】

```
他低头看你：“你是替身，就该守规矩。”
你笑了笑：“可惜她不愿回来。”
他说：“她回来了。”
你眼底泛红，却还嘴角上扬：“那我走，行了吧？”
他不语，只是在你转身那刻，忽然攥紧了拳头——
“池念，你不能走。”

### 🌙【梦境回忆杀 · 男主疯批线触发】

```

他说：“你这种女人，什么资格救她？”

后来你走了。
他查到真相那天，疯了一样冲进你发布会后台，低声说：“池念，回来，我求你。”
