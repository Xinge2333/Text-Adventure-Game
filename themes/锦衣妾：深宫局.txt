## 🧩 一、【基础身份设定】  
**用途：定义主角人设及初始属性系统**  

```text
【主角设定】  
姓名：沈芙  
身份背景：宰相庶女（母亲早亡，幼年被送往外宅抚养）  
核心动机：逆袭封妃，夺回母亲之名，查清当年真相  
性格标签：温婉克制、外柔内刚、记仇精算型  

初始属性：  
- 魅力：75（从不艳压，却能令人回眸）  
- 心计：65（出招不多，但往往致命）  
- 地位：30（第七妾，名不见经传）  
- 宠爱值：20（王爷偶尔留意，却未曾夜宿）  
- 敌意值：40（其她妾室对你虎视眈眈）  
- 心理状态：冷静（擅于藏锋不露）
```

✅ 主角模版采用【庶女→野心型】路线，前期低调，中期爆发，具备高度逆袭潜力。

## 🧩 二、【宫廷世界观】  
**用途：构建剧情背景与世界逻辑**

```text
【宫廷设定】  
时间背景：雍元三年  
政权结构：皇帝-太后-摄政王（暂摄朝政）-权臣/外戚  
宫廷冲突主轴：摄政王拥兵权与皇权微妙平衡，后宅妾室争宠以求“正位”，多方势力暗流汹涌  
典型场景：掖庭主院、瑶光殿月宴、秋水榻、洗墨阁、狄园书室、昭仁台

【敌对势力初设】
- 第一反派：贵妾·苏若音  
- 势力：礼部尚书嫡女，亦是你的同父异母姐姐，现为王府“四妾”，传闻最得宠  
- 初始敌意值：70  
- 她的动机：扶正为妻，铲除所有“血缘上的威胁”，巩固娘家地位

【辅助男角色】
- 摄政王·萧御庭：冷情克制，擅于权术，怀疑身边一切，不轻信他人  
- 暗卫·言枳：前世与你有斩不断纠葛的黑衣护卫，忠犬疯批，有暗线可探  
- 太监总管·程福海：笑里藏刀，疑似为太后安插的钉子  
- 小皇子·赵晗：聪慧而警觉，你曾在花园救过他，他记得你
```

✅ 整体政局采用【权宠倾轧型】路线：男主处权力巅峰，女主借宠进阶，妾室内卷拉满。

## 🧩 三、【属性与心理系统】  
**用途：驱动数值机制的逻辑规则**

```text
【属性系统说明】
- 魅力：影响宠爱值获取，出席宴会、遇见意外时他人反应倾向  
- 心计：判断局势、识破谎言、抓住对手破绽  
- 地位：调动嬷嬷/宫女资源，接触王府核心场所机会  
- 宠爱值：与王爷的夜会频率、赠物、扶正概率密切相关  
- 敌意值：妾室敌意高时易触发“穿小鞋”“诬陷”“冷落”等副本

【心理状态机制】
- 冷静：心计属性加成+5%，隐藏剧情触发率+10%  
- 焦虑：判断选项时成功率下降，易误判陷阱  
- 愤怒：可能获得“狠辣一击”机会，也可能惹祸上身

例：当你保持“冷静”，面对姐姐陷害时可选择“以退为进”并精准揭穿。
```

✅ 后期将开放“心理崩坏”机制——触发暴走/黑化结局线。

## 🧩 六、【礼仪考试系统】  
**用途：模拟妃嫔社交、晋位仪轨与礼制审核场景**

```text
【礼仪考试系统说明】  
礼仪是决定妃嫔能否获得封赏、参与重要场合的关键指标。王府每季将举办一次“内府礼仪比试”与“太后亲审册礼”，成功将获得：

- 地位提升  
- 宠爱值提升（因皇族面前表现优异）  
- 心计提升（以礼制压制他人、识破陷阱）

【考试内容类别】
1. 宫廷礼节：对贵妃/王妃敬茶、晨起请安仪式  
2. 嫔妃穿戴：对颜色、花纹、场合的精准匹配  
3. 诵经/诗礼：在太后座前献诗，或讲《女则》  
4. 暗题审查：如“你若为正妃，如何处理宠妾之争？”（需选择答法）

【系统判定方式】
- 若【心计 > 70】可识破隐性陷阱题  
- 若【魅力 > 80】可获得“众人默许”额外加成  
- 若【敌意值 > 60】，可能遭遇“舞裙被动手脚”“所用茶水被换”等事故

【考试结果】
1. 三科皆优：地位 +10，宠爱 +10，敌意 -5  
2. 一科失误：地位 +3，宠爱 +5，敌意维持  
3. 被人陷害失败：敌意 +10，宠爱 -5，地位 -5，触发“羞辱事件”
```

✅ 推荐将该机制引入【月末事件触发】，玩家需提前准备。

## 🧩七、【册封流程机制】  
**用途：模拟“由妾升嫔/由嫔进位”的核心制度流程**

```text
【册封系统说明】  
王府妃嫔等级由低至高为：妾 → 小嫔 → 嫔 → 贵嫔 → 正妃。册封程序需要满足多重条件：

【触发条件】
- 宠爱值 ≥ 60（王爷主动提出册封）  
- 地位 ≥ 50（王府上下认可）  
- 敌意值 ≤ 60（无明显敌对）  
- 礼仪考试通过（或太后背书）

【流程步骤】
1. 王爷提名（剧情触发“赐礼”场景）  
2. 王妃/贵妃审议（如现任王妃反对将触发“内宅对质”剧情）  
3. 内务府拟册（你需准备三日内的应对策略，管理场面）  
4. 太后御准（若你在“晚膳”或“问安”中表现不佳，会延迟册封）

【失败可能】
- 王爷动摇（宠爱值波动）  
- 妾室联名反对（敌意值过高）  
- 你被误导签署假册书（需“心计 ≥ 75”才能识破）

【成功收益】
- 地位 +20，宠爱 +15  
- 解锁“独立院落管理权”  
- 可调遣女官/嬷嬷/小厮，自建“资源小循环”
```

✅ 此机制建议作为【中期主线节点】，一旦成功将大幅打开资源管理权限。

## 🧩 八、【王府账目推理机制】  
**用途：打造高智商线索推演事件，可用于反杀陷害者、掌握府内经济控制权**

```text
【账目系统说明】  
你发现瑶光院近月账册混乱，常有“多支”“假货”记录。若能利用此线索揭发苏若音贪腐，将触发“摄政王密谈”剧情，直接影响地位与宠爱值。

【玩法机制】
1. 日常获取：在浣衣局、狄园书房、太监密报中拾得账册残页  
2. 资料对比：需调动“心计”与“人脉资源”逐步拼凑出完整账目  
3. 推理演绎：逐步识别虚假货单、贪墨入私房、偷梁换柱等痕迹  
4. 关键判断题例：

- “为何瑶光院每月绸缎用量远超主妃所居？”  
- “‘苏记商铺’账目为何反复出现？”  
- “‘六两金叶子’为何出现在沈芙签字栏？”（陷害关键）

【系统判定】
- 心计 ≥ 70：可识别错乱逻辑  
- 魅力 ≥ 80：可说服总管程福海提供辅助信息  
- 地位 ≥ 60：可要求王爷召人当面对质  

【成功推理】
- 王爷宠爱值 +20（“她竟能一眼识出破绽……”）  
- 苏若音敌意 -10（受挫但未退场）  
- 解锁“掌账副管”权限（调控府中支出）

【失败风险】
- 被反诬告“私查内务”  
- 心计若 <60，可能被误导陷入“假账陷阱”，敌意+15  
- 开启“洗墨阁审讯线”，需依靠太后/暗卫支援脱身
```

✅ 此机制适合与【月宴】或【赏花节】等活动剧情结合，作为中后期逆转剧情利器。
